Metodologia Semântica

Este portal não é apenas um diretório comum. Foi construído utilizando Tecnologias de Web Semântica, onde cada monumento e instituição é um recurso único numa rede de dados interligados.

"O uso de RDF e SPARQL permite que o sistema compreenda que 'Braga' é um Distrito dentro da região 'Norte' sem necessidade de redundância de dados."
