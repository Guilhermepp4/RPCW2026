1. Quais são as personagens presentes na história e a que espécie animal pertencem?
___________________________________________________

PREFIX : <http://www.semanticweb.org/guilhermepinho/ontologies/2026/4/untitled-ontology-76/>

SELECT ?nomePersonagem ?especie WHERE {
    ?personagem a ?classe .
    FILTER (?classe IN (:Animal, :Corvo, :Raposa))
    
    ?personagem :temNome ?nomePersonagem ;
                :temTipo ?especie .
}

15. Que jogos demoram mais de 60 minutos a jogar (playingTimeMinutes)?
___________________________________________________

PREFIX : <http://www.di.uminho.pt/rpcw2026/PG60263#>

SELECT ?jogo ?nomeJogo ?tempo WHERE {
    ?jogo a :Jogo ;
          :name ?nomeJogo ;
          :playingTimeMinutes ?tempo .

17. Qual a distribuição de jogos por editora, ordenada descendentemente pela quantidade de jogos? (O
resultado será uma lista de pares: Editora, número de jogos que publicou)
___________________________________________________

PREFIX : <http://www.di.uminho.pt/rpcw2026/PG60263#>

SELECT ?nomeEditora (COUNT(?jogo) AS ?numJogos) WHERE {
    ?editora a :Editora ;
             :name ?nomeEditora ;
             :publishedGame ?jogo .
}
GROUP BY ?nomeEditora
ORDER BY DESC(?numJogos)

19. Quais os jogos com mecânicas mais complexas? (o resultado será uma lista de jogos: id, nome e lista
de mecânicas, apenas para jogos que têm mais de 3 mecânicas associadas)
___________________________________________________

PREFIX : <http://www.di.uminho.pt/rpcw2026/PG60263#>

SELECT ?jogo ?nomeJogo (GROUP_CONCAT(?nomeMecanica; separator=", ") AS ?listaMecanicas) WHERE {
    ?mecanica a :Mecanica ;
              :name ?nomeMecanica ;
              :usedInGame ?jogo .
    
    ?jogo :name ?nomeJogo .
}
GROUP BY ?jogo ?nomeJogo
HAVING (COUNT(?mecanica) > 3)

20. Uma ludoteca escolar quer planear um evento e precisa da lista completa de autores e mecânicas
envolvidas se utilizarem exclusivamente jogos da categoria Family. Produz uma lista sem repetições
que inclua o nome do jogo, o nome dos seus criadores e as suas mecânicas.
___________________________________________________

PREFIX : <http://www.di.uminho.pt/rpcw2026/PG60263#>

SELECT DISTINCT ?nomeJogo (GROUP_CONCAT(DISTINCT ?nomeAutor; separator=", ") AS ?criadores) (GROUP_CONCAT(DISTINCT ?nomeMecanica; separator=", ") AS ?mecanicas) WHERE {
    ?jogo a :Jogo ;
          :category "Family" ;
          :name ?nomeJogo .
    
    ?autor a :Autor ;
           :name ?nomeAutor ;
           :designedGame ?jogo .
    
    ?mecanica a :Mecanica ;
              :name ?nomeMecanica ;
              :usedInGame ?jogo .
}
GROUP BY ?nomeJogo
ORDER BY ?nomeJogo
